## Kyoshiro — Front of Code

I inspect WordPress sites and service them — faster, safer, cheaper to keep.
I hand the site back rather than taking it into custody.
**Sometimes the answer is: keep it.**

Based in Saku, Nagano, Japan. Solo, working directly with the people who own the site.

### What I'm doing right now

I'm working out how far a WordPress site can be cut down before it stops needing
looking after, and I'm measuring it on my own site first — before I offer it to anyone.
Sometimes that means rebuilding it as static; sometimes it means leaving WordPress
in place and taking things out.

**The procedure is not finished yet.** I would rather say that than imply otherwise.
What I can show today is the sample below. It is real, deployed, and built end to end —
and still in progress: the images in it are placeholders.

When I publish measurements, they will be my own, taken under stated conditions.

## Kyoshiro／Front of Code

WordPress サイトの点検と整備をしています。速く、安全に、維持費が下がる状態にしてお返しします。
預かり続けるのではなく、整備してお返しする形です。**残したほうがいい場合もあります。**

長野県佐久市。一人でやっていて、サイトを持っている方と直接やり取りします。

### いま取り組んでいること

WordPress のサイトを、どこまで削れば手がかからなくなるのかを、まず自分のサイトで測りながら詰めています。
作り直すのが正解のこともあれば、WordPress のまま中身を減らすのが正解のこともあります。

**手順はまだ固まっていません。** 固まっていない段階で「できます」とは書かないことにしています。
いま出せるのは下の Astro のサンプルです。実在して公開していますが、
**画像がプレースホルダのままで、まだ仕上げ中**です。

数値を出すときは、自分で測ったものを、計測条件と一緒に出します。
